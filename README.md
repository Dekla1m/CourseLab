# CourseLab — ускоритель шифра «Кузнечик»

Учебный проект аппаратного ускорителя для 128-битного блочного шифра «Кузнечик» с 256-битным ключом. Целевая ПЛИС — Artix-7 `xc7a100tcsg324-1`. Проект открыт в Vivado 2022.2. Исходники и тестбенчи написаны на Verilog.

## Текущее состояние

- `kuz_TOP` выбирает режим ENC или DEC. В каждом тракте по одному раундовому модулю с обратной связью. С готовым ключом результат появляется через **10 тактов** от приёма 128-битного блока. Следующий блок можно принять на 11-м такте.
- Общий `kuz_key_schedule` готовит K1…K10 за **33 такта** после приёма нового ключа. Ключ загружается по отдельному `valid/ready`. В течение сообщения оба тракта используют один набор. Переключение ENC/DEC и повторная загрузка того же ключа используют готовый набор. [Интерфейс и расписание](docs/ENCRYPT_TOP.md)
- Реализованы UART RX/TX, FIFO, разбор HEX-ключа и сборка входных блоков ENC. На уровне системы предстоит связать эти модули, закончить форматирование ENC/DEC, реализовать загрузчик программы, CPU и системную шину. [Архитектура](docs/ACCELERATOR_ARCHITECTURE.md), [загрузчик и шина](docs/SYSTEM_BUS_AND_PROGRAMMER.md)

## Что проверено

- Четыре симуляции XSim для банка ключей, ENC, DEC и `kuz_TOP` прошли **29 из 29 сценариев**. Проверены контрольные векторы RFC 7801, смена ключа между сообщениями, переключение ENC/DEC и тактовые задержки. [Журналы симуляций](outputs/unit_tests/)
- В имплементации тестовой обвязки `test_impl_IO_low` при **100 МГц** получены **WNS +0,161 нс** и **WHS +0,040 нс**. Схема заняла **5 377 LUT и 1 915 триггеров**. Эти цифры относятся к внутренним путям тестовой обвязки. Финальный системный top, внешние интерфейсы и плата ждут отдельной проверки. [Подробности](docs/CONTEXT.md#аппаратная-база-для-сравнения)

## Как открыть и проверить

Открой [CourseLab.xpr](CourseLab.xpr) в Vivado 2022.2. Тестбенчи находятся в `sim_1`. Выбери нужный модуль как Simulation Top и запусти Behavioral Simulation. Например, `tb_kuz_top` проверяет оба режима и загрузку ключа через один экземпляр `kuz_TOP`.

Из корня проекта те же тесты можно запустить через PowerShell. Подставь путь к каталогу `bin` установленного Vivado.

```powershell
$vivadoBin = 'C:/Xilinx/Vivado/2022.2/bin'
& ./work/check_crypto_tests.ps1 -VivadoBin $vivadoBin -Test kuz_top
& ./work/check_fifo_and_key.ps1 -VivadoBin $vivadoBin -Test fifo
```

Другие значения `-Test` и правила работы с проектом перечислены в [контексте](docs/CONTEXT.md) и [AGENTS.md](AGENTS.md).

## Дальше

Обсуждается полный конвейер для ENC и DEC. В каждом направлении девять раундов и финальный XOR. Для независимых блоков цель — один блок за такт после заполнения. По текущему размещению оценка обоих трактов составляет **около 30 тыс. LUT из 63 400**. Разбиение отдельного раунда на несколько стадий рассматривается отдельно как способ повысить частоту. [План и критерии проверки](docs/NEXT_STEPS.md#конвейеры-enc-и-dec)
