# Источники проекта и рабочий список литературы

Рабочий реестр источников по алгоритму, ПЛИС и оформлению тезисов. Идентификаторы S01 и далее используются для обсуждения. Библиография готового текста включает источники, процитированные в тезисах.

## Как понимать происхождение

- **Прислан пользователем**: ссылка или документ прямо присутствует в сообщении пользователя.
- **Привлечён в прошлом чате**: источник предложен/процитирован агентом. Это не доказывает, что пользователь лично прочитал и применил его при разработке.
- **Найден сейчас**: дополнительная литература, не подтверждённая как использованная в разработке.
- **Проверен сейчас** означает чтение соответствующего текста или страницы первоисточника. Для остальных материалов указано ограничение проверки.

По истории подтверждена **одна статья Хабра**. Других ссылок Хабра в доступных сообщениях не найдено. Добавлять вымышленные «использованные статьи» нельзя.

## Предлагаемое ядро будущей библиографии

Для тезисов объёмом 1–2 страницы ориентир — 3–5 содержательно необходимых ссылок, а не весь этот реестр:

1. S01 — определение алгоритма.
2. S04 — известные архитектуры, включая Matrix.
3. S07 **или** S05 — если действительно ставится задача оптимизации XOR-схем.
4. S09 — если в тексте нужны особенности архитектуры ПЛИС.
5. S02 или S06 — при необходимости для проверки алгоритма или акцента на постоянных умножителях.

Это предложение для согласования. Хабр S03 остаётся в истории разработки, даже если для короткого научного текста будут выбраны более прямые источники. В окончательную библиографию включать только процитированные в тезисах материалы; каждой записи должна соответствовать осмысленная ссылка в тексте.
