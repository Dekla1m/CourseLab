# CourseLab — ускоритель шифра «Кузнечик»

Учебный проект аппаратного ускорителя для 128-битного блочного шифра «Кузнечик» с 256-битным ключом. Целевая ПЛИС — Artix-7 `xc7a100tcsg324-1`. Проект открыт в Vivado 2022.2. Исходники и тестбенчи написаны на Verilog.

## Текущее состояние

- `kuz_TOP` выбирает режим ENC или DEC. В каждом тракте девять четырёхстадийных раундов и финальный XOR. С готовым ключом результат появляется через **37 тактов** от приёма 128-битного блока. Внутри сообщения принимается **один блок за такт**. После входного `last` приём нового сообщения ждёт выхода хвоста.
- `kuz_key_schedule` готовит K1…K10 за **33 такта на 100 МГц**. `kuz_key_loader` передаёт набор с подтверждением в активный банк `kuz_TOP` на **200 МГц**. ENC и DEC используют один набор на всё сообщение. [Интерфейс и расписание](docs/ENCRYPT_TOP.md)
- Реализованы UART RX/TX, FIFO, разбор HEX-ключа и сборка входных блоков ENC. На уровне системы предстоит связать эти модули, закончить форматирование ENC/DEC, реализовать загрузчик программы, CPU и системную шину. [Архитектура](docs/ACCELERATOR_ARCHITECTURE.md), [загрузчик и шина](docs/SYSTEM_BUS_AND_PROGRAMMER.md)

## Что проверено

- Пять модульных TB для расчёта и передачи ключей, ENC, DEC и `kuz_TOP` прошли **21 из 21 сценария** в XSim. Проверены контрольные векторы RFC 7801, непрерывная подача, пустые слоты, сброс, смена ключа и переключение ENC/DEC. [Журналы симуляций](outputs/unit_tests/)
- В версии с тестовой обвязкой с ограниченными IO `test_impl_IO_low` при **200 МГц** получены **WNS +0,009 нс** и **WHS +0,039 нс**. Схема заняла **52% LUT**. Эти цифры относятся к внутренним путям тестовой обвязки. Финальный системный top c полной обвязкой, внешние интерфейсы ждут отдельной проверки. [Подробности](docs/CONTEXT.md#аппаратная-база-для-сравнения)
