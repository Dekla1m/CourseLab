# Требования НИТ-2026 и рекомендации руководителя

Требования к оформлению по информационному письму НИТ-2026 и рекомендации руководителя.

## Источники требований и приоритет

1. Прямое сообщение пользователя: этапность согласования и запрет размещать написанные агентом тезисы в Google Документе.
2. Переданные пользователем рекомендации руководителя: содержание, уровень подробности и секция.
3. Информационное письмо `C:/Users/cosmo/Downloads/nit-2026-informatsionnoe_pismo.pdf`, страница 2: формальные требования. Страница отрендерена и просмотрена.
4. [Официальная страница](https://rsreu.ru/faculties/fvt/kafedri/saprvs/konferentsiya-nit): название конференции, сроки и секции.
5. [НИТ-2025, том 2](https://rsreu.ru/component/docman/doc_download/20801-nit-2025-t2): ориентир по стилю. Старые публикации не заменяют требований письма 2026 года.


## Содержание по рекомендации руководителя

- Целевая секция: «Информационные технологии в промышленности».
- Кратко обозначить предметную область и актуальность — ориентировочно несколько строк.
- Сформулировать цель и следующие из неё задачи.
- Назвать свой подход к решению, сохраняя конкретику без низкоуровневых деталей реализации.
- Обозначить ожидаемый результат; уже полученные результаты отделять от планируемых.
- Включить литературу, на которую действительно ссылается текст.
- Совместное редактирование предполагается в Google Документе. Документ уже предоставлен пользователем, поэтому создавать дубликат на данном этапе не требуется.

Это рекомендации по структуре связного текста, а не обязательные названия отдельных разделов. Сведения об аппаратуре, типе преобразования и критериях сравнения позволяют сохранить конкретику; длинный разбор байтов, масок и функций Python/Verilog для тезисов избыточен.

## Формат по информационному письму

- Объём: **1–2 страницы**.
- Формат сдачи: документ текстового процессора **Microsoft Word**. Работа в Google Docs служит подготовкой; итоговый Word-файл следует проверить отдельно.
- Бумага: **A4**.
- Поля: **20 мм со всех сторон**.
- Шрифт: **Verdana, 12 пт**.
- Межстрочный интервал: **одинарный**.
- Основной текст: **по ширине**.
- Отступ первой строки: **0,5 см**.
- Автоматическая расстановка переносов.
- Название: **ПРОПИСНЫМИ БУКВАМИ, полужирное, по центру**.
- Следующая строка: авторы, **инициалы перед фамилией**, по центру.
- Далее: научный руководитель, Ф.И.О., учёная степень и учёное звание, по центру.
- Далее: организация, по центру.
- После шапки: пустая строка, затем текст.
- Перед библиографическим списком: пустая строка.
- Библиография: по указанному в письме **ГОСТ 7.1–2003** (в письме набрано «7.1.2003»).
- Ссылки в тексте: **в квадратных скобках**, например [1]. Номера назначить по готовому тексту; S01… в SOURCES.md — только рабочие идентификаторы.
- Формулы: письмо требует Microsoft Equation 3.0.
- Рисунки: BMP или JPEG, 200×200 dpi; подпись отдельно от изображения.
- Количество формул и рисунков минимальное.

Не добавлять от себя УДК, аннотацию, ключевые слова, английский дубль или отдельную титульную страницу: письмо этого не требует. Отсутствие требования не является запретом, но при лимите 1–2 страницы такие элементы не нужны без отдельного указания организаторов.

В образце организация выделена жирным, а заголовок библиографии — курсивом по центру; описательная часть письма не задаёт эти выделения явно. Для будущего оформления это детали образца, а не отдельные однозначные требования. В тексте письма порядок инициалов явно задан только для авторов; пример руководителя дан как «Петров П.П.».

## Подготовка файла

Оформление предоставленного Google Документа выполняется после отдельного указания пользователя. Сгенерированный текст тезисов в него не вставляется. Итоговый Word-файл проверяется по параметрам письма, включая переносы и формулы. Данные шапки сверяются с автором и руководителем.

Пример подачи материала — НИТ-2025, том 2, с. 160–161. Параметры оформления берутся из письма 2026 года. [Рабочий список источников](SOURCES.md)
